# نظام إدارة التكوين — SCHOOL

تطبيق ويب عربي RTL، يعمل كملف واحد، بدون بيانات تجريبية عند البدء.

## التشغيل محليا
- افتح `index.html` مباشرة في المتصفح، أو
- شغّل خادما بسيطا: `python -m http.server 8000` ثم افتح `http://localhost:8000`

## النشر على GitHub Pages
1. أنشئ مستودعا جديدا على GitHub.
2. ارفع كل محتويات هذا المجلد (index.html + README.md).
3. من Settings → Pages → Branch: `main` / `/ (root)` → Save.
4. سيكون الرابط: `https://<username>.github.io/<repo>/`

## الوظائف
- الإعدادات الأولية: أسماء المراحل، أنواع التكوين
- الهيئة: الاسم والمسؤول
- المتربصون: إضافة فردية + إدخال جماعي (لصق قائمة) + بحث فوري + ترقيم صفحات
- السرايا: إضافة وحذف وتوزيع
- المراحل: من الإعدادات، والدورة يمكن أن تكون "بدون مرحلة"
- البرامج والدورات: كل برنامج له دورة واحدة على الأقل، وكل دورة لها بداية ونهاية مع تحقق
- البرقيات: توجيه والتحاق، فردية وجماعية، مع زر حذف مستقل لكل برقية + تأكيد + تراجع
- المعاينة: نافذة داخلية تعرض المستند من البيانات الحالية
- النسخ الاحتياطي: تصدير / استيراد JSON
- التنبيهات: نظام Toast موحد
- الخط: Cairo فقط — لا يستعمل Tahoma أبدا

## التخزين
في هذه النسخة المخصصة لـ GitHub Pages، البيانات محفوظة في `localStorage` في المتصفح.
لنسخة إنتاجية حقيقية، يوصى بنقل التخزين إلى Supabase / PocketBase / Firebase مع أدوار وصلاحيات.
