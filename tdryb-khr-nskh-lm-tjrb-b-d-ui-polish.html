ملخص التدقيق — كل مسار حفظ بعد الإصلاح

القراءة عند الفتح من مصدر واحد: settings, trainees, units, programs, participations, references, users, report_templates. كل كتابة تمر عبر records.create / records.replace مع await ثم إعادة القراءة. عند الفشل تبقى النافذة مفتوحة ويظهر السبب نصاً، ولا تظهر رسالة نجاح كاذبة.

مسار الحفظقبلبعد الإصلاحالنتيجة
الإعدادات الأولية (settings)كان الحفظ يعمل لكن زر الحفظ بلا تعطيل أحياناًawait + reload + تعطيل الزر + رسالة خطأ حقيقيةيعمل
الهيئة (settings)حفظ عبر نفس المجموعةنفس المصدر + تعطيل أثناء الحفظ + بقاء النموذج عند الفشليعمل
متربص واحد (trainees)يعمل عند النجاححقول موحّدة rank/name/regNo/unitId/status + إبقاء النافذة عند الفشليعمل
سرية (units) + نقل متربصيعملنفس المجموعة + إدخال جماعي يتحقق من الأسماء الموجودةيعمل
برنامج (programs)يعمل + فتح نموذج الدورة بعدهأُبقي السلوك + خطأ داخل النافذة عند الفشليعمل
دورة (داخل programs.courses)يعملتحقق بداية/نهاية + مرحلة أو بدون مرحلة + خطأ داخل النافذةيعمل
تمارين ختامية (references)يعملتعطيل الزر + رسالة خطأ حقيقيةيعمل
تعيين (participations)كان يغلق النافذة حتى عند الفشللا تغلق عند الفشل — خطأ داخل النافذة + إنشاء مشاركات فعليةأُصلح
برقية فردية/جماعية (participations)الجماعية كانت تغلق النافذة عند الفشلreplace لكل مشارك مع await + بقاء النافذة عند الفشلأُصلح
مستخدم / مرجعية / قالب تقريرتعملنفس المصدر + تعطيل + خطأ داخل النافذةيعمل
نسخة احتياطية / استيرادالاستيراد كان يخلط رسالة JSON مع أخطاء الحفظ ولم يستورد settingsيستورد settings و report_templates + عدّاد محفوظ/متخطى + خطأ حقيقيأُصلح
إدخال جماعي للمتربصينكان داخل نافذة ويرفض السطر عند غياب الرتبة/السريةظاهر دائماً في الصفحة + قيم افتراضية + معاينة + عدّادات + لا يغلق عند الفشلأُصلح
إدخال جماعي للسراياكان يسمح بتكرار أسماء موجودةيتحقق من الأسماء الموجودة + عدّادات مكرر/صالحأُصلح
استقرار التطبيق — ما أُصلح لمنع التعطل التلقائي
  • Error Boundary حول التطبيق كله: أي خطأ في الرسم يعرض رسالة وزرّي «العودة للرئيسية» و«إعادة المحاولة» بدل الشاشة البيضاء.
  • التحميل مرة واحدة فقط عند الفتح، بلا إعادة محاولة تلقائية ولا مؤقتات متكررة.
  • الحفظ بضغطة واحدة: حارس يمنع حفظين متزامنين + تعطيل الزر أثناء الحفظ.
  • الإدخال الجماعي يُحلَّل بعد توقف الكتابة 400ms فقط، وبحد أقصى 100 سطر في المعاينة.
  • كل القوائم بمفاتيح مستقرة (id) وكل الحسابات المشتقة داخل useMemo مع حراسة Array.isArray.
